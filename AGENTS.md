# Работа с анализом личности

Начинай с [personality.md](personality.md), выбирай маршрут по запросу и читай только нужные документы.

Числа и параметры карты вычисляют скрипты; модель объясняет результаты и проверяет пригодность рекомендаций.

Рабочие персональные данные, отчёты и окружение хранятся в игнорируемых `runs/` и `.venv/` либо вне репозитория.

В публичных примерах допускаются только явно синтетические данные.

Для разработки: сохранять контракт JSON, проверять затронутые формулы и границы, перед push запускать `.venv/bin/python -m unittest discover -s tests -v`, CLI-прогон, `git diff --check` и отдельное ревью.

Изменение HTML проверять на 375 и 1280 px, включая печать, клавиатуру и длинные значения.

Изменение формулы или зависимости требует обновить версию расчётного метода и тесты, пересчитать зависимые результаты и повторить проверку интерпретаций.

Публикация HTML на сайте и обновление его доступа требуют отдельного поручения; генерация локального отчёта этого не делает.
