# Миграция promt-personality

Исходная версия: `dd123270ff39c90194a9b6a3eb6b25b491f3f2df`.

## Разделение работы

Буквы, редукции, квадрат, циклы и 36 оценок перенесены из рассуждений модели в Python.

Недостающие формулы явно зафиксированы как соглашение arithmetic-v1; это выбранная воспроизводимая конвенция, а не утверждение о единственной школе нумерологии.

Опросник и ключ сохранены без изменений, ничьи учитываются, низкий балл не объявляется доказательством вытеснения.

Astronomy Engine заменяет приближённые элементы планет по умолчанию; исправлены DST gap/fold, проверка диапазона и координат, сходимость солнечной дуги, округление знаков и порядок компонент графа.

Средний узел используется и в API, и в CLI; узлы и ASC/MC сохраняют явно отмеченные ограничения.

## HTML и независимые артефакты

Один Markdown-ответ заменён расчётным JSON, отдельным JSON интерпретаций и автономным HTML.

Числа и таблицы рендерятся из расчёта, ссылки интерпретаций привязаны к его хешу; HTML-значения экранируются.

Исходные данные сохраняются, запись результата атомарная, входной файл нельзя выбрать выходным даже через симлинк или жёсткую ссылку.

Внешние сервисы не вызываются при расчёте и открытии отчёта; сетевой доступ нужен только для первоначальной установки зависимости.

Первоначальный референс изучен по локальному исходнику личного сайта; наличие страницы подтверждено чтением хостинга 05.11.2026.

Затем по прямому уточнению автора создана отдельная дизайн-система для аудитории, интересующейся астрологией: выбран вариант «Мягкая мистика: молочный, сливовый, пыльная роза».

Личный стиль сайта не является действующим каноном этого шаблона; новый канон — [design-system.md](design-system.md).

Личный текст, дата рождения и доступы автора не перенесены в публичный пример; сайт и пароль не менялись.

## Проверка

Независимое ревью обнаружило ложную отметку «расчёт недоступен» в двух синтезных разделах; исправление проверено на полном narrative и закреплено тестом.

Луна сверена с JPL Horizons на трёх датах, Солнце — по равноденствию USNO, время — по официальному примеру Astronomy Engine; источники и границы проверки сохранены в [ephemeris.md](ephemeris.md).

Ограниченные эталоны не являются полной аттестацией всех планет на всём временном диапазоне.

Проверки интерфейса включают устаревшие хеши, чужой narrative, неверные ссылки, частичные данные, недопустимые даты и числа, экранирование HTML и сохранность входных данных.

Общий прогон: 59 тестов, CLI calculate/check/render, закреплённый инфостиль, ссылки и формат навыка — успешно.

Браузерная проверка на 375 и 1280 px: нет общего горизонтального переполнения, внешних запросов и ошибок страницы, якоря существуют и раскрывают источники, закрытые таблицы видны при печати.

Независимая визуальная проверка потребовала понятной шкалы астрокарты: добавлены 12 секторов, номера планет и открытая легенда, повторная проверка принята.

По уточнению автора исходные данные открыты в начале, жизненные циклы выделены в самостоятельную главу, а общий разбор стоит в конце после восьми подробных глав.

Схема JSON обновлена до v2: добавлены life_cycles, topics и summary_topics, полные ссылки на Солнце и Землю обеих карт, дату дизайна, метод и суммы слов гематрии.

Первоначальный глубокий текст подготовлен по готовому инфостилю promt-copywriting; отдельный субагент социальных поглаживаний отредактировал 50 текстовых полей, сохранив структуру, числа и источники.

Содержательное ревью нашло две неполные группы ссылок, они дополнены; определение вызовов уточнено, общий итог прямо отделяет воспроизводимость вычислений от доказанности интерпретации характера.

Холодный читатель прочитал весь видимый текст и подтвердил понятность общего портрета, конкретность действий и отсутствие навязанной биографии; цвет и тон дополнительно обозначены как справочная деталь.

Локальные результаты и SHA-256 артефактов сохраняются в игнорируемом runs/verification/.

## Оптимизация контекста

На текущем синтетическом примере полный calculations JSON содержит 43 591 Unicode-символ, команда summary выдаёт 17 686, сохраняя 75 фактов и ограничения без полного набора активаций и исходного текста.

Для инфостиля доступен индекс из 123 карточек; команда выбора передаёт целые нужные карточки с критериями проверки, а не всю методичку.

Это замеры объёма передаваемых артефактов, не расхода токенов провайдера и не стоимости полного цикла с редактированием и проверками.
